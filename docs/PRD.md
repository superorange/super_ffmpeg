# Super Toolbox — 产品需求文档 (PRD)

> 版本 v0.4 · 2026-09-25 · 状态：媒体工作室 + 开发者工具箱已交付

## 1. 愿景

一个**本地优先、开箱即用的桌面全能工具箱**。把开发者、创作者日常要用到的零散小工具
（视频转码、图片压缩、JSON 格式化、正则测试、JWT、哈希……）收进一个统一、好看、快的应用里。

- **不上传**：所有处理都在本机完成（FFmpeg 内置；JS 用系统自带的 JavaScriptCore；预览用 WebKit）。
- **不用记命令**：常用操作图形化，高级用户随时能看到/复制等价命令。
- **一个入口**：⌘K 搜索任何工具；首页拖入任意文件，自动打开对应工具。

## 2. 目标用户

| 画像 | 典型需求 | 痛点 |
| --- | --- | --- |
| 内容创作者 | 剪一段压到 8 MB 发群、转竖屏、做 GIF、iPhone 照片转 JPG | 在线工具要上传、有水印、限大小 |
| 开发 / 运维 | JSON 格式化与对比、JWT、Base64、正则、时间戳、Cron、HTML 片段预览 | 工具散落在十几个网站，还要担心数据泄露 |
| 普通用户 | 提取音频、剪一段、合并视频、压缩图片 | 专业软件太重，命令行太难 |

## 3. 信息架构

```
首页（搜索 · 媒体工作室入口 · 万能拖放区 · 引擎状态 · 最近使用 · 分类工具卡片）
├── 媒体工作室   ← 一个工作区，10 个功能标签页
├── 图片          图片压缩与转换
├── 数据 · JSON   JSON 格式化 / JSON 对比 / JSON↔YAML / JSON 生成代码 / CSV↔JSON
├── 前端开发      HTML 实时预览 / JS 运行 / Markdown 编辑器 / CSS 格式化 / 颜色工具 / 正则测试
├── 编码与加密    Base64 / 编码转换 / URL 解析 / JWT / 哈希校验 / 进制转换
├── 文本          文本对比 / 命名转换 / 文本处理 / 占位文本
├── 生成与时间    UUID / 密码 / 二维码 / 时间戳 / Cron
└── 文件          （路线图：批量重命名、重复文件查找）
任务中心（所有后台任务：进度 / 取消 / 重试 / 日志 / 在访达中显示）
设置（外观 · 语言 · 引擎 · 输出 · 并发）
```

**万能拖放**（首页）：视频/音频 → 媒体工作室；JSON/YAML/CSV/Markdown/HTML/CSS/JS → 对应工具；
图片 → 图片工具；其它任何文件 → 哈希校验。工具页本身也接受拖放。

## 4. 媒体工作室（v0.4 重做）

**用户反馈**：旧版每个功能都要重新拖一次视频。**新形态**：拖入一次，所有功能围绕它。

```
素材库条（多个文件，点击切换当前文件）
预览舞台（播放头所在帧，进程内解码） │ 文件信息卡
时间线（胶片条 · 播放头 · 入点/出点手柄 · I/O/←/→/Esc 快捷键）
功能标签：转换 压缩 剪辑 音频 GIF 变速画面 合并 截图 信息 命令行
选项区（按宽度 1–3 栏）
运行栏：当前文件 / 全部 N 个 · 仅选区 · 输出位置 → 文件名 · 命令 · 开始
```

| 功能 | 与时间线的关系 | 批量 |
| --- | --- | --- |
| 转换 / 压缩 / 音频 / 变速画面 | 可选「仅处理选区」（输入端 `-ss/-t`，重编码下精确到帧；目标大小按选区时长算码率） | ✅ |
| 剪辑 | 直接使用选区；未选区时提示去时间线选择 | — |
| GIF | 使用选区；无选区时取播放头起 5 秒 | ✅ |
| 截图 | 单帧 = 播放头；按间隔 / 缩略图墙可用选区 | ✅ |
| 合并 | 使用整个素材库的顺序，可拖动排序 | — |
| 信息 | 当前文件的容器与每条流 | — |
| 命令行 | `{input}` = 当前文件，批量模式逐个运行 | ✅ |

变速画面的旋转/翻转/画幅会实时显示在预览舞台上（画幅用遮罩框表示）。

## 5. 其他模块

- **图片压缩与转换**：HEIC / WebP / PNG / JPG / AVIF / TIFF 输入（HEIC 平铺网格正确合成）；输出 JPG、AVIF、PNG、TIFF、BMP；
  质量、最长边缩放（只缩不放）；始终移除 EXIF / GPS。
- **JSON 格式化**：格式化 / 压缩 / 转义 / 去转义、缩进、键排序、错误定位（行列 + 跳转）、树视图（复制路径/值）、JSONPath 查询。
- **JSON 对比**：忽略键顺序的结构化差异（新增 / 删除 / 修改 / 类型变化）+ 规范化后并排对比。
- **JSON 生成代码**：TypeScript / Dart（含 fromJson/toJson）/ Go / Swift Codable / Kotlin serialization；数组元素合并推断、可选与可空。
- **HTML 实时预览**：HTML/CSS/JS 三栏编辑，WebKit 实时预览，console 输出与报错回传到控制台，导出 HTML。
- **JS 运行**：macOS 自带 JavaScriptCore（`jsc`），每次运行独立进程、5 秒超时强杀；console、Promise、定时器（虚拟时钟）、最后表达式作为结果。
- **Markdown 编辑器**：GFM（表格、任务列表、删除线），格式化工具栏，编辑/分栏/预览，字数与阅读时间，打开/保存 .md，导出 HTML。
- **正则测试**：实时高亮、分组与命名分组、替换预览（`$1` `$<name>` `$&`）、常用正则库、i/m/s/u 标志。
- **颜色工具**：HSV 取色板、HEX/RGB/HSL/HSV/CMYK/Flutter 转换、WCAG 对比度、明暗色阶。
- **编码**：Base64（文本、文件、图片预览、Data URI、URL 安全、二进制识别与保存）；URL/HTML 实体/Unicode/Hex/二进制；URL 解析。
- **JWT**：解码、exp/iat/nbf 人性化显示、HS256/384/512 签名校验与生成。
- **哈希**：MD5/SHA-1/SHA-224/256/384/512/CRC32、HMAC、文件流式计算（后台 isolate）、期望值比对。
- **文本**：词级高亮的并排 diff（忽略空白/大小写、只看差异、复制补丁）、12 种命名风格、统计与行操作（排序/去重/自然排序…可撤销）、中英文占位文本。
- **生成与时间**：UUID v4/v7、ULID、Nano ID、ObjectId（及时间戳反解）；密码（熵评估）；二维码（文本/Wi-Fi、容错、配色、PNG）；时间戳（自动识别秒/毫秒/微秒/ISO/RFC 2822）；Cron（字段解析、未来 12 次运行）。

## 6. 非功能需求

- 冷启动 < 1s 可交互；引擎检测异步。
- 进程执行以参数数组调用（无 shell 拼接）；文件名含引号/空格/`$`/中文安全。
- 中文 / English；浅色 / 深色 / 跟随系统。
- macOS 优先（Apple Silicon），内置 FFmpeg 9.0.2（GPL）。

## 8. 成功指标

- 首次使用者 30 秒内完成「拖入 → 选区 → 压缩到 8 MB → 拿到文件」。
- 目标大小压缩结果 100% 不超过设定值（含「仅选区」）。
- 任务失败时 100% 可看到原因。
- 所有开发工具即输即得（< 50 ms 反馈），无需点「转换」。
